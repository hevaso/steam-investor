# Steam Market Algorithmic Terminal — учебен симулатор

Локален Go бекенд + HTML фронтенд, който показва как работят техническите индикатори
(RSI, MACD, Bollinger Bands, EMA/SMA) върху цена на предмет.

## ⚠️ Важно (прочети първо)
Това е **симулатор за учене**, не реални Steam цени, и индикаторите **не предсказват
бъдещето със сигурност**. Те описват какво вече се е случило. Оранжевият „конус“ на
графиката е нарочно — показва, че бъдещето е диапазон от възможности, не една линия.

## Как се пуска

1. Инсталирай Go (https://go.dev/dl/).
2. В папката с `main.go`:
   ```
   go run main.go
   ```
   Трябва да видиш: `Сървърът е пуснат успешно на http://127.0.0.1:8080`
3. Отвори `index.html` в браузъра (двоен клик или през Live Server).
4. Горе вдясно индикаторът трябва да светне зелено: **● НА ЖИВО**.

(По желание) тестове на математиката:
```
go test -v
```

## Какво прави всеки индикатор (на прост език)

- **SMA (Simple Moving Average)** — обикновена средна на последните N цени. Изглажда шума, за да видиш тренда.
- **EMA (Exponential Moving Average)** — като SMA, но дава по-голяма тежест на скорошните цени, затова реагира по-бързо.
- **RSI (0–100)** — измерва инерцията. Над 70 = „свръхкупен“ (качи се бързо, може да се охлади). Под 30 = „свръхпродаден“. **Това е измервател, не оракул.**
- **MACD** — разликата между бърза и бавна EMA. Хистограма над 0 = възходящ импулс; под 0 = низходящ.
- **Bollinger Bands** — средна линия + ленти на 2 стандартни отклонения. Цена близо до горната лента = опъната нагоре; до долната = опъната надолу.

Всеки индикатор „гласува“ BUY / SELL / HOLD. Сборът дава обобщения сигнал.
**Често не са съгласни** — точно това е истината: няма магическа формула.

## Файлове
- `main.go` — пазарен двигател + индикатори + два API endpoint-а (`/api/tick`, `/api/market-data`)
- `index.html` — фронтенд (графика, индикатори, баланс/инвентар)
- `verify_test.go` — проверки, че RSI/SMA/MACD дават правилни стойности

## Следваща стъпка: реални Steam цени
Сменяш симулирания random walk в `stepPrice()` с реални данни. Публичният Steam endpoint
`https://steamcommunity.com/market/priceoverview/` дава текуща цена (но е силно
rate-limited и неофициален — чети правилата на Steam). История на цените изисква вход в
акаунт. За начало симулаторът върши идеална работа за учене.
